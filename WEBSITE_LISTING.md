## What’s included

### Customer-facing store
- Full-bleed cinematic homepage (video hero, collections, featured products, brand story, gifting, testimonials, Instagram-style gallery, newsletter)
- Shop + product detail pages with weight variants and reviews
- Category/collection pages (Almonds, Cashews, Pistachios, Walnuts, Dates, Dried Fruits, Seeds, Gift Boxes)
- Cart drawer + checkout flow
- Build-your-box / custom gift experience
- Dedicated gifting and brand story pages
- Customer account area (Supabase auth)

### Commerce & ops
- Stripe Checkout integration
- Coupon system (API + admin UI)
- Admin dashboard for products, orders, and coupons
- Order status management
- Catalog served from code + Supabase-backed admin workflows

### Catalog seed
- ~16 curated premium SKUs across 8 collections
- Multiple weight/price variants per product
- Gift box tiers (Classic / Signature / Grand)
- Product imagery ready under `/public/products`

### Tech stack
| Layer | Stack |
|--------|--------|
| Framework | Next.js 15 (App Router) |
| UI | React 19, Tailwind CSS 4, Framer Motion |
| Auth / DB | Supabase (SSR clients, profiles, roles) |
| Payments | Stripe |
| Language | TypeScript |
| Fonts | Cormorant Garamond + Outfit |

### Deliverables to buyer
- Full source code (this repository)
- Environment variable template (Supabase + Stripe keys)
- Seed product data and brand assets
- Admin role model (`profiles.role = admin`)
- Handover notes for deploy (Vercel recommended)
